- Helper CLI

[Repository](https://github.com/augustofrade/gru-lua) · [Releases](https://github.com/augustofrade/gru-lua/releases)

### C# Web Driver
A C#/.NET **implementation of the WebDriver** protocol, rather than a Selenium wrapper, with a Javascript-Like API for easy of use.

[Repository](https://github.com/augustofrade/csharp-web-driver)

### Bob CLI
A general-purpose CLI toolkit for development and everyday use. Made in Typescript

Saves texts, file templates, paths, cmd aliases, **run scripts anywhere** through the CLI, generate QR code generation, including **secure secret** storage using the operating system's
secret manager, an **HTTP server with hot reload**, **CSS minification**, regex testing and more.
and other utilities.

[Repository](https://github.com/augustofrade/bob-cli)

### Red-It Extension

A **Firefox browser extension** that filters and blocks selected content on Reddit while keeping track of blocked content and usage statistics.

The extension is published through the Firefox Add-ons store.

[Repository](https://github.com/augustofrade/red-it-extension) · [Mozilla Add-ons Store](https://addons.mozilla.org/en-US/firefox/addon/red-it/)
